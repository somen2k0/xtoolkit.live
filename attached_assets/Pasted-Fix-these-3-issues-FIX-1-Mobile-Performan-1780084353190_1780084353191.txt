FIX 2 — http://xtoolkit.live redirect issue
===================================================

Google is seeing http://xtoolkit.live/ as a
separate URL. Add explicit HTTP to HTTPS redirect
in vercel.json:

In vercel.json add to redirects array:
{
  "source": "/:path*",
  "has": [
    {
      "type": "header",
      "key": "x-forwarded-proto",
      "value": "http"
    }
  ],
  "destination": "https://xtoolkit.live/:path*",
  "permanent": true
}
