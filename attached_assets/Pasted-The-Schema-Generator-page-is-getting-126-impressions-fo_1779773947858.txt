Heading: "Frequently Asked Questions"

Q: Is JSON-LD schema free to use?
A: Yes. JSON-LD structured data is an open
   standard developed by schema.org and is
   completely free to implement on any website.

Q: Does JSON-LD schema directly improve rankings?
A: JSON-LD schema doesn't directly boost rankings
   but it enables rich results which increase
   click-through rates. Higher CTR signals to
   Google that your content is valuable, which
   can indirectly improve rankings over time.

Q: How do I test if my JSON-LD schema is valid?
A: Use Google's free Rich Results Test at
   search.google.com/test/rich-results or
   Google's Schema Markup Validator at
   validator.schema.org

Q: What is the difference between JSON-LD and
   JSON schema?
A: JSON-LD is structured data markup for search
   engines using schema.org vocabulary. JSON Schema
   is a different specification used to validate
   JSON data structure in APIs and applications.
   They are unrelated despite similar names.

Q: Can I use multiple JSON-LD schemas on one page?
A: Yes. You can include multiple JSON-LD script
   blocks on a single page for different schema
   types. For example a page can have both an
   Article schema and a BreadcrumbList schema.
