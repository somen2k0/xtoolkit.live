FIX 2 — OTP AUTO-DETECTION AND COPY
===================================================

Add automatic OTP detection and a prominent copy
button when a message is opened.

Create a function detectOTP(text: string): string | null
that finds OTP codes in email content:

const OTP_PATTERNS = [
  /\b(\d{4})\b/g,           // 4-digit OTP
  /\b(\d{5})\b/g,           // 5-digit OTP  
  /\b(\d{6})\b/g,           // 6-digit OTP (most common)
  /\b(\d{7})\b/g,           // 7-digit OTP
  /\b(\d{8})\b/g,           // 8-digit OTP
  /code[:\s]+(\d{4,8})/gi,  // "code: 123456"
  /otp[:\s]+(\d{4,8})/gi,   // "OTP: 123456"
  /pin[:\s]+(\d{4,8})/gi,   // "PIN: 123456"
  /password[:\s]+(\d{4,8})/gi, // "password: 123456"
  /verification[:\s]+(\d{4,8})/gi, // "verification: 123456"
  /token[:\s]+(\d{4,8})/gi, // "token: 123456"
];

Priority: prefer 6-digit codes near words like
"code", "otp", "verify", "verification", "pin"

When an email is opened:

FIX 3 — MOBILE TEXT SELECTION
===================================================

On mobile, text in the message body is not
selectable. Fix this:

Add these CSS properties to the message body:
-webkit-user-select: text !important;
-moz-user-select: text !important;
-ms-user-select: text !important;
user-select: text !important;
-webkit-touch-callout: default !important;

This enables text selection on iOS and Android.
